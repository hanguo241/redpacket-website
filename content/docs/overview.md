# RedPacket 开发者文档

RedPacket 是一个即插即用的 Web3 红包基础设施。本文档面向项目方开发者，帮助你在 30 分钟内完成红包功能的接入。

---

## 核心概念

### 混合架构

- **资金安全** — 红包资金锁定在智能合约中，平台不触碰用户资产
- **免合约部署** — 合约由 RedPacket 部署和维护，项目方只需调用 API
- **跨链支持** — 一套 API 接入所有主流公链
- **零 Gas 领取** — 平台代付 Gas 模式，用户无需持有 Native Token

### 红包类型

| 类型 | 子类型 | 说明 |
|------|--------|------|
| 普通红包 | 均分 | 所有人领取金额相同，无需口令 |
| 普通红包 | 随机 | 金额随机分配，增加趣味性 |
| 口令红包 | 均分 | 输入正确口令才能领取 |
| 口令红包 | 随机 | 口令验证后随机分配金额 |

### 领取模式

| 模式 | 谁付 Gas | 适用场景 |
|------|---------|---------|
| 自领 (Self-Claim) | 用户 | 有 Gas 的老用户 |
| 代领 (Proxy-Claim) | 平台 | 新用户引流，零门槛体验 |

## 快速开始

1. 注册账号 → 获取 AppKey / AppSecret
2. 调用创建红包 API → 获取待签名交易数据
3. 用户钱包签名 → 广播上链
4. 提交 txHash 到后端完成记录
5. 分享红包链接给用户
